Scratchpads —— 暂存区图形管理器

一个图形界面，用来查看和管理 Umbriel 的 scratchpad（暂存区）： 看到每个暂存区里存着哪些窗口，并且直接看到它们的真实画面。 按一个快捷键呼出，Esc 关掉，不用记命令。

1. 它能帮你做什么

Umbriel 的 scratchpad 可以把窗口“收起来”暂存，需要时再拿出来。 但平时你只能靠记忆：哪个暂存区里到底放着什么？

这个工具给你一个总览面板：

👀 看见内容

每个窗口显示真实画面缩略图。即使窗口正被收在暂存区里、屏幕上看不见，也能看到它的内容。

🖱️ 一个快捷键

呼出面板，点一下就切换显示 / 隐藏、聚焦、归还或关闭窗口。

🔎 快速定位

输入几个字就能过滤出你想要的窗口，不用在一堆标题里找。

➕ 随手整理

在界面里新建或删除暂存区，不用手写配置文件。

💡

最实用的一点：暂存区里的窗口是“隐身”的，你平时看不到它们。 有了缩略图，你收起来的终端、浏览器、编辑器现在都一目了然。

2. 开始使用

第一步：确认已经安装

在终端里执行下面这行，如果有版本号输出，就说明已经装好了：

scratchpads-umbriel --version

如果提示“命令未找到”，请让安装者（或你自己）执行：

meson setup build
ninja -C build
sudo ninja -C build install

第二步：给它绑一个快捷键 ★

这是唯一必须做的一步。打开 Umbriel 的快捷键配置 ~/.config/umbriel/binds.toml，加入一行： 

[keybinds]
"Mod+S" = "spawn:scratchpads-umbriel"

键位 "Mod+S" 可以换成你喜欢的任意组合。 保存后需要让 Umbriel 重新读取配置（多数情况下按一下快捷键或重载配置即可生效）。

第三步：呼出面板

按下你刚设置的快捷键，屏幕中央会出现一个半透明遮罩 + 面板。 再按一次同样的快捷键，面板就会收起。

关闭面板还有两种方式：

  • 按 Esc；
  • 用鼠标点击面板之外的暗色区域。（点面板里面不会关闭）
ℹ️

面板打开时会独占键盘输入，所以你在里面按键不会跑到别的窗口去； 一旦关闭，键盘就立刻交还给原来的窗口。

3. 界面导览

  • 1标题栏：右侧依次是连接状态、缩略图开关 ▦、重新读取配置 ⟳、关闭 ✕。
  • 2缩略图开关 ▦：点亮时显示窗口画面；关掉后变成一行行紧凑的文字条目，同时停止抓取画面（更省电）。
  • 3搜索框：输入窗口标题或应用名即可实时过滤。
  • 4暂存区标题行：名称与状态标签，右侧是「显示 / 隐藏」「上一个 / 下一个」「⋮ 更多」。
  • 5窗口卡片：就是窗口画面本身。左上角可能有一个状态小标签，底部是标题和两个小按钮。
  • 6底栏：新建暂存区、重新读取配置、打开配置文件。

状态标签怎么看

标签含义
focused这是当前正在使用的窗口。
visible窗口正显示在屏幕上（没有被收起）。
urgent窗口在请求注意（比如终端有提示音或新消息）。
hidden（在暂存区标题行上）这个暂存区的窗口都收起来了。
implicit这是 Umbriel 默认的暂存区，不是你手动创建的。

4. 常用操作速查

我想……怎么做
打开 / 收起面板 按你绑定的快捷键；或用 Esc、点击面板外关闭。
看看某个窗口长什么样 直接看卡片里的缩略图。
跳到某个窗口 点击它的缩略图。窗口会被切到前台；如果它正被收在隐藏的暂存区里，会顺便自动显示出来。
把某个窗口从暂存区拿出来 点卡片右下角的 ↩。窗口会回到它当初保存的那个工作区。
关掉某个窗口 点卡片右下角的 ✕。
显示 / 隐藏整个暂存区 点暂存区标题行右侧的 显示 / 隐藏 按钮。原来的窗口会一起出现或收起。
一次只显示一个窗口 用标题行的 ◂ ▸ 轮流切换暂存区里的成员。
把当前窗口收进某个暂存区 点该暂存区的 ⋮ → Store focused window here。
把当前窗口搬到某个暂存区 点 ⋮ → Move focused window here（明确地把它移过去）。
折叠一个暂存区 点名称左边的 ▾ / ▸ 箭头。
找到某个窗口 在搜索框里输入标题或应用名的一部分。

⋮ 更多菜单里有什么

  • Focus next window —— 聚焦这个暂存区里下一个已显示的窗口。
  • Store focused window here —— 把当前窗口收进这个暂存区。 它是个开关：如果窗口已经在这里，再来一次就会把它取出来。
  • Move focused window here —— 把当前窗口搬进这个暂存区。
  • Reveal in configuration —— 用默认编辑器打开定义了该暂存区的配置文件。
  • Delete scratchpad… —— 删除该暂存区（红色，只有本工具创建的才会出现这一项）。

5. 窗口预览（缩略图）

面板里的每个窗口都是一个缩略图，画面实时取自合成器，不是图标也不是截图文件。

✨

被收进暂存区的窗口同样能看到画面。 这是它和普通任务栏最大的不同 —— 那些“隐身”的窗口不再是黑盒。

关于画面的几点说明

  • 刷新频率：面板打开时，画面大约每 4 秒更新一次，所以是新近的内容。
  • 省电：面板一关，抓取立刻停止，完全不占用资源。
  • 比例：不同形状的窗口会按比例缩小并居中，两侧可能留出空白，这是正常的（不会裁掉内容）。
  • 暂时看不到：刚打开面板的瞬间缩略图可能还在生成，会先显示应用名首字母（如 GC）和“正在抓取…”字样，稍等一下即可。
  • 抓不到画面时：卡片会显示 no preview，但其它功能照常可用。

两个相关按钮

按钮作用
▦ 缩略图开关关掉后，卡片变成一行行的文字条目（标题 + 应用名 + 两个小按钮），并且停止抓取画面。适合只想快速点一下、或想省电的时候。
⟳ 重新读取配置重新读取 Umbriel 配置、清空画面缓存并立即重新抓取一遍。配置改动后按它最省事。

6. 新建 / 删除暂存区

新建

  1. 点底栏的 ＋ 新建暂存区。
  2. 输入名称，也可以顺便填一个“空的时候运行什么命令”。
  3. 确认即可。

新建出来的暂存区会被写进工具自己管理的一份文件 （scratchpads-managed.toml，和你的主配置放在同一个目录）， 并自动让 Umbriel 重新加载配置。

⚠️

第一次新建时会多问一句：需要把你的主配置文件里加入对这个文件的引用。 工具会先备份你的配置（config.toml.scratchpad-manager.bak）， 然后只做最小改动 —— 注释和排版都会原样保留。

⚠️

请注意：一旦有了具名暂存区，Umbriel 就会取消默认的 default 暂存区。 原来收在里面的窗口会回到它们各自保存的位置（不会丢失）。 界面在创建前会先把这件事告诉你。

删除

点该暂存区的 ⋮ → Delete scratchpad…，确认即可。 只有由本工具创建的暂存区才会显示这一项，你自己手写的配置不会被改动。

另外，default 这个名字是 Umbriel 保留的，不能用来新建。

7. 搜索与过滤

标题栏下方的输入框可以实时筛选窗口，匹配的是窗口标题和应用名：

  • 输入 fire → 只剩标题或应用名里含 “fire” 的窗口。
  • 输入 term → 只剩终端类窗口。
  • 清空输入框 → 恢复全部。

没有窗口匹配的暂存区会被自动隐藏，看起来更清爽。

8. 小技巧

  • 把它当成“暂存区监视器”。 用 Mod+S 打开看一眼就 Esc， 两秒钟就能确认收起来的窗口都还在。
  • 用缩略图代替切换窗口。 找到目标后直接点缩略图， 比先切换工作区再找窗口快得多。
  • 窗口很多时先搜索。 输入应用名（如 kitty）能立刻缩短列表。
  • 不想看到画面就关掉 ▦。 面板会变成紧凑列表， 信息量不减，还更省电。
  • 面板外观是跟随主题的。 颜色和圆角都取自你当前的 Umbriel 主题。

9. 常见问题

按键没反应，面板不出现？

依次检查：

  • 快捷键有没有写对（~/.config/umbriel/binds.toml 里的 [keybinds] 段落）。
  • 改完配置后 Umbriel 有没有重新加载。
  • 在终端里直接跑 scratchpads-umbriel 能不能打开面板。
缩略图位置一直显示首字母，一直没变成画面？

说明这台机器的合成器没有提供按窗口抓取画面所需的协议， 或者该窗口暂时没有被渲染过。面板会退化成文字列表， 切换、聚焦、归还、关闭这些功能都不受影响。

面板里少了一个窗口？

面板只列出存在于暂存区里的窗口。普通显示在桌面上的窗口不会在这里出现 —— 这正是暂存区管理器的用途。用搜索框时也可能把它过滤掉了，清空输入框试试。

点了「显示」之后，屏幕上多了好几个窗口？

这是预期的：显示一个暂存区会把它的所有成员一起放出来。 如果只想一个个来，用 ◂ ▸ 逐个切换。

新建暂存区时它问我“要不要修改主配置”，可以拒绝吗？

可以。但如果拒绝，新建的暂存区不会被 Umbriel 读取到， 你需要自己把 scratchpads-managed.toml 加进主配置的 [include] files 里。

它会改坏我的配置文件吗？

不会。本工具只写自己管理的那一份文件；对主配置只做一次最小的“加一行引用”， 而且会先备份、保留注释与格式。你自己写的暂存区也永远不会被删除。

面板一打开，键盘就被它“吃”掉了？

是的，这是刻意设计：这样你在面板里的按键不会误发到后面的窗口。 按 Esc 或点面板外关闭后，键盘会立刻还给原来的窗口。

左下角的连接状态是 ○ 重连中…？

Umbriel 没在运行，或者通信接口暂时不通。面板会自动每秒重试， 恢复后会变回 ● 已连接，无需重启。

10. 进阶：命令行

日常使用不需要命令行，但它在脚本和排查问题时很有用。

scratchpads-umbriel [选项]

  -c, --config <路径>   指定 Umbriel 配置文件，而不是按默认顺序查找
      --socket <路径>   指定通信接口（默认 $UMBRIEL_SOCKET）
      --window          用普通窗口打开，而不是全屏覆盖层
      --dump            以纯文本打印所有暂存区及其窗口，然后退出
      --add <名称>      新建一个暂存区
      --spawn <命令>    配合 --add，指定“暂存区为空时运行什么”
      --remove <名称>   删除一个暂存区
  -h, --help            显示帮助
  -v, --version         显示版本

不打开界面，直接看清单：

$ scratchpads-umbriel --dump
config:  /home/me/.config/umbriel/config.toml
managed: /home/me/.config/umbriel/scratchpads-managed.toml  (included)
loaded:  5 file(s)

[default] (implicit)  1 window(s), 1 visible
    visible  kitty                ~

输出里的 visible / hidden 表示该窗口当前是显示还是被收起。

ℹ️

--window 会打开一个普通窗口而不是覆盖层， 适合在其它合成器上试用，或者调试。

11. 出问题了怎么办

  1. 先看面板左下角的提示。 操作失败时这里会直接显示原因 （例如“未知的暂存区名”或“配置目录不可写”）。
  2. 用 --dump 看原始数据。 scratchpads-umbriel --dump 会打印工具看到的全部暂存区与窗口， 方便对照是不是配置没生效。
  3. 没有画面？ 属于正常降级，功能不受影响；想确认的话， 在终端里直接运行 scratchpads-umbriel 观察输出。
  4. 配置目录不可写？ 新建 / 删除会被拒绝并说明原因。 把你的用户配置放到 ~/.config/umbriel/ 下即可。
  5. 想回到干净状态？ 删除 ~/.config/umbriel/scratchpads-managed.toml， 并从主配置的 [include] files 里去掉那一行引用。 之前创建的暂存区就会消失。
